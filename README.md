# The Hearth & Thorn Grimoire 🌿

A forest-green Gothic Cottagecore recipe PWA with editable recipes, cooking mode, favorites, shopping list, offline support, and optional Google Sheets syncing.

## Publish on GitHub Pages

**Important:** Upload the files *inside* this folder to the repository root, not the containing folder. The ZIP is a convenience for downloading; GitHub Pages needs the unzipped files.


1. Create a **new public GitHub repository** (for example `hearth-and-thorn-grimoire`).
2. Upload `index.html`, `style.css`, `app.js`, `recipes.json`, `manifest.webmanifest`, `icon.svg`, and `sw.js` to the repository root. **Do not upload `Code.gs` with a real sync key** (this supplied file contains no key).
3. Under **Settings > Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, then save.
4. Open the Pages URL on your phone; use the browser's **Add to Home Screen / Install App** option.

## Connect Google Sheets (optional)

1. Create a new blank Google Sheet in your Google account.
2. Open **Extensions > Apps Script**. Replace the starter code with the supplied `Code.gs` file.
3. Open **Project Settings > Script Properties** and add `SYNC_KEY` with a long, random secret (e.g., generated by a password manager). **Never put this key into a public GitHub file.**
4. **Deploy > New deployment > Web app**. Choose **Execute as: Me** and **Who has access: Anyone**. Authorize and copy the URL ending in `/exec`.
5. In the cookbook, go to **Settings**, paste the `/exec` URL and your secret key, and click **Save connection**.
6. On the first device, click **Upload recipes to Sheets**. On another device, enter the same URL and key and click **Download recipes from Sheets**.

### Sync limitations and safety

- This first version **does not automatically pull changes** from other devices. Editing a recipe sends a best-effort upload; use Download before editing on a second device to avoid overwriting newer changes.
- The browser sends uploads in `no-cors` mode due to Apps Script's cross-origin limitations, so it **cannot confirm upload success**. Verify by downloading on another device or checking the Sheet.
- **Uploading replaces the entire cloud recipe list; downloading replaces the entire local recipe list.** Keep backups and avoid simultaneous edits.
- The read endpoint uses JSONP because Google Apps Script web app CORS is restrictive. The shared key is sent as a URL parameter for reads; it can appear in browser/network history or logs. **This is suitable only for non-sensitive personal recipes**, not private information or a public multi-user service. For robust secure login, use a dedicated backend with authentication instead.
- The public GitHub Pages app contains only client code and starter recipes, not your sync key. Your key is stored in browser localStorage on each device; do not use this setup on shared devices.
- Offline edits remain in localStorage. Clear browser data only after backing up recipes to Sheets.
- Ingredient quantities are currently free text; automatic scaling is not yet implemented.
- The six included recipes are **reconstructed drafts**, not guaranteed exact copies of previous conversations. Review and edit before cooking.

## Files

- `index.html`, `style.css`, `app.js`: app UI and behavior
- `recipes.json`: six starter recipe drafts
- `sw.js`, `manifest.webmanifest`, `icon.svg`: installable PWA and offline caching
- `Code.gs`: optional Google Apps Script backend; paste into Apps Script, not required for GitHub Pages
